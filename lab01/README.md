## Розподіли випадкових величин: неперервні та дискретні

**Варіант:** 5  
**Порядковий номер студента:** $N = 5$

Програма обчислює параметри заданих розподілів випадкових величин, будує відповідні графіки та зберігає їх у папку `plots`.

## Використані розподіли

| Позначення | Розподіл | Параметри для варіанта 5 |
|---|---|---|
| a | Бернуллі | $p = \frac{1}{N+1} = \frac{1}{6} \approx 0.167$ |
| b | Біноміальний | $n = N+2 = 7$, $p = \frac{1}{6} \approx 0.167$ |
| c | Пуассона | $\lambda = N+10 = 15$, $k_{max}=N+5=10$ |
| d | Рівномірний | $a=-N=-5$, $b=N=5$ |
| e | Нормальний | $\mu=N=5$, $\sigma^2=\frac{N}{2}=2.5$ |
| f | Парето | $\alpha=x_0=N=5$ |
| g | Стьюдента | кількість ступенів вільності $df=N=5$ |
