# Теорія прийняття рішень

Репозиторій містить лабораторні роботи з дисципліни ТПР.

## Лабораторні роботи

| Робота | Тема | Матеріали |
|---|---|---|
| [Лабораторна №1](lab01/) | Розподіли випадкових величин: неперервні і дискретні | Програма та графіки |
| [Лабораторна №2](lab02/) | Бінарні відношення та основні операції над ними | [Результати](lab02/README.md) |
| [Лабораторна №3](lab03/) | Агрегування та факторизація бінарних відношень | [Результати](lab03/README.md) |
| [Лабораторна №4](lab04/) | Методи обчислення середніх величин | [Результати та графік](lab04/README.md) |
| [Лабораторна №5](lab05/) | Методи експертного оцінювання | [Метод Терстоуна та результати](lab05/README.md) |
| [Лабораторна №6](lab06/) | Лінійна та максимінна згортка | [Результати](lab06/README.md) |
| [Лабораторна №7](lab07/) | Метод ідеальної точки | [Результати та графік](lab07/README.md) |

Кожна лабораторна робота знаходиться в окремій папці. Навчальні методички та інші допоміжні матеріали зберігаються поза цим репозиторієм.

## Встановлення залежностей

```powershell
py -m pip install -r requirements.txt
```
