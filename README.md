# Дискретні моделі та теорія прийняття рішень

Репозиторій містить лабораторні роботи з дисципліни ДМТПР.

## Лабораторні роботи

| Робота | Тема | Матеріали |
|---|---|---|
| [Лабораторна №1](lab01/) | Дискретні розподіли ймовірностей | Програма та графіки |
| [Лабораторна №2](lab02/) | Бінарні відношення та операції над ними | [Результати](lab02/README.md) |
| [Лабораторна №3](lab03/) | Агрегування та факторизація бінарних відношень | [Результати](lab03/README.md) |

Кожна лабораторна робота знаходиться в окремій папці. Навчальні методички та інші допоміжні матеріали зберігаються поза цим репозиторієм.

## Встановлення залежностей

```powershell
py -m pip install -r requirements.txt
```
